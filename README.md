# Telegram Bot — gada1ka 🎲

Развлекательный Telegram-бот, написанный на Python с использованием асинхронного фреймворка aiogram 3.

## 🚀 Функционал
- Обработка стандартной команды `/start` и текстовой кнопки «🔍 Старт».
- Удобное Reply-меню для взаимодействия с пользователем.
- Случайный выбор и отправка стикеров-предсказаний по команде `/gadai` или кнопке «🎲 Гадание».

## 🛠 Технологии
- **Python 3.10+**
- **aiogram 3.x** — асинхронный фреймворк для Telegram Bot API
- **asyncio** — асинхронная обработка событий
